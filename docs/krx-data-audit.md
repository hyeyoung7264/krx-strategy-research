# KRX 공식 데이터 초기 품질 감사

검토일: 2026-09-29. 로컬 인증키로 읽기 전용 공식 API를 호출한 결과의 **공유 가능한 요약**이다. 원본 응답·키·가격 시계열은 공개 저장소에 넣지 않고 무시된 `artifacts/`에 보존한다. [KRX Open API 이용 조건](https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO002.jsp)을 따른다. 이 작은 표본은 과거 전체의 시점 인증이나 수익성 증거가 아니다.

| 날짜 | 서비스 | 관측 결과 |
|---|---|---|
| 2026-09-22 | KOSPI/KOSDAQ 일별매매정보 | 942 / 1,820행 |
| 2026-09-23 | KOSPI/KOSDAQ 일별매매정보 | 942 / 1,821행 |
| 2026-09-23 | KOSPI/KOSDAQ 종목기본정보 | 942 / 1,821행; 각 시장의 일봉 ticker 집합과 일치 |
| 2026-09-23 | KOSPI/KOSDAQ 지수 일별시세 | 서로 다른 지수 시리즈 54 / 40행 |
| 2026-09-25·28 | 일별매매정보 일부 또는 양 시장 | HTTP 200이지만 0행; 휴장·서비스 결측 판정 보류 |

9월 22→23일 코스닥에 1종목이 추가됐다. 23일 종목기본정보의 상장일도 그 날짜였다. 상장 전 가격 행을 만들어 전 기간에 현재 종목을 복제하면 생존 종목 편향과 가짜 체결이 생기므로, `LifecycleEvents`의 `LISTED`/`DELISTED` 사건으로 상장 구간을 명시한다. 상장 중의 가격 누락은 여전히 거부한다. 원본의 날짜별 응답이 과거에 실제로 공개됐던 구성과 같은지, 과거 공시 시각을 입증하는지는 별도 검토가 필요하다.

네 일봉 원본으로 2세션·5,525개 행·신규상장 사건 1건의 로컬 진단 dataset을 실제 CLI에서 만들었다. 이 실험에서는 산업을 `UNREVIEWED`, 모든 종목의 회원/거래가능 플래그를 false로 표시하고 `PointInTimeCertified=false`로 유지했다. 따라서 데이터 파이프라인과 상장 경계 검증의 작동 확인일 뿐 전략 성과나 주문 가능성의 증거가 아니다.

23일 일봉 2,763행 중 115행은 시가·고가·저가·거래량·거래대금이 모두 0이고 종가는 양수였다. 엔진은 이 보고값을 보존하되 0원 체결은 금지한다. 장 시작 시 보유 가치 산정에는 이미 공개된 종가만 사용한다. 이 행의 정확한 거래정지 원인이나 주문 가능 상태는 공식 거래정지 이력과 대조하기 전에는 추정하지 않는다. `Tradable=true` 입력이 있어도 0원 시가 행에는 주문하지 않는다.

다음 증거가 필요하다: 거래소 세션 달력과 빈 응답 사유, 날짜별 상장·상장폐지·재상장·거래정지 이력, 기업행위에 따른 보유 권리와 정산 금액, 산업 분류의 과거 시점, 매일 종가의 실제 제공 시각, 실제 수수료·세금과 체결 슬리피지. 기본정보의 `SECT_TP_NM`은 소속부이며 산업 분류가 아니다. 보유 중 상장폐지 등으로 행이 사라지면 정산 증거가 없으므로 백테스트는 중단한다. Paper 장부의 종목 구성 변경 지원은 후속 작업이다.
