# 검증 현황

최신 목표를 우선 반영하고 Owner가 선택한 일봉·수일 보유, OpenDART 공시/기업정보, KRX 공식 일봉 기준으로 구현했습니다. 실제 주문은 구현하지 않았습니다.

## 실행하여 확인한 항목

- .NET 10 솔루션과 C# 엔진 빌드.
- 모멘텀·평균회귀의 네 사전 등록 후보, 학습/검증/미래 테스트 분리, 5개 walk-forward fold와 마지막 holdout.
- 비용 전/후, 순청산가치, EV/MDD/Sharpe 등 지표, 위험·regime 중단과 통계 평가.
- 미래 값 변형, 다음날 공개 지연, 거래정지, gap 손실, 포지션 비중, 데이터 오류, 재현성, 버전/승격 gate 테스트.
- 실제 PostgreSQL 18 임시 독립 인스턴스에 OHLCV/실험 저장 및 조회, 원본 UPDATE/DELETE 거부.
- OpenDART 및 KRX의 공식 요청/응답 명세에 대한 mock HTTP·파싱·시점 보존 테스트.
- 기존 49개 자동 테스트가 Release에서 전체 통과(독립 PostgreSQL 연결 포함). 이후 전체 테스트 수와 최신 실행 결과는 아래 연구 확장 검증에 기록. 일반 실행은 PostgreSQL 연결 미설정 시 해당 테스트 하나를 명시적으로 skip.
- 빌드 소스 manifest와 실행 파일 SHA-256을 보존하고, 소스 변경 후 오래된 실행 파일 사용을 차단.
- 전체 연구 아카이브를 실제 CLI로 재현하여 모든 fold·holdout·평가가 일치함을 확인. 재현은 새 독립 증거로 세지 않음.
- 동시 증거 저장 시 완성 문서 하나만 게시, 직렬화 실패 시 깨진 증거 미게시, paper commit 후 사본 유실 시 거래 재실행 없는 복구 검증.
- 고정 seed 합성 연구를 실행했고 결과는 HOLD_OR_REJECT. 실패 결과, 원본 입력, 실행 소스와 해시, 지표 및 보고서를 보존.
- KRX 명시적 날짜 목록 수집, 요청 예산, 호출 간격, 중단 후 재개, 원본 보존, 빈 응답 검토 중단, 변조 검출, 동시 수집 거부와 오류 메시지 비노출을 mock 수집 테스트로 검증.
- 실제 CLI에서 키 미설정 시 HTTP 송신 없이 REQUEST_FAILED receipt를 보존함을 확인. 이 실행은 API 인증/실데이터 수집 검증이 아님.
- Paper 평가는 최신 확정 장부에 연결하고 관측별 재계산을 검사. 조작된 내보낸 사본/확정 잔고/인증 표시/감사 hash/후보 수, 과거 상태 선택, 실행 버전 변경, 실적을 넣은 시작 상태를 거부하는 테스트 통과. 장부 없는 직접 평가는 진단용으로 제한.
- Paper 시작은 완전한 연구 아카이브의 재현을 요구. 평가 판정/holdout 지표/walk-forward 통과 여부/데이터 분류 변경, 원본·소스 증거 누락을 거부하고 재현된 부적격 연구도 시작하지 않는 테스트 통과.

## 연구 확장 검증

- 최신 전체 Release 검증: 84개 중 83개 통과, PostgreSQL 연결 미설정으로 1개 skip. CLI 빌드 0 warning/0 error. 기본 cohort-demo와 완전한 아카이브 재현을 실제 CLI로 실행해 모든 결과가 일치함을 확인.
- 단일 cohort에서 전략군별 선택 및 공유 자본 포트폴리오의 walk-forward/최종 검증/holdout을 평가. 기본 네 후보의 사전 검정 수는 개별 4 + 조합 4 = 8.
- holdout 가격 변경으로 학습 기반 선택과 결합 검증이 바뀌지 않음을 검증. 완전한 schema 2 아카이브에서 두 전략군·포트폴리오·통계 보정 수를 재현.
- 계산 분기 검증용으로 명시한 가공 데이터에서 실제 통과 연구가 단일 cohort 아카이브로 paper 시작까지 연결됨을 확인. 이 데이터는 실제 시장 연구나 forward 증거로 내보내지 않음.
- 데이터 revision·종목 집합·코드 변경으로 기존 holdout 거래일을 재사용하지 못하며, 겹치지 않는 새 기간과 동시 예약 충돌 처리를 검증.
- OpenAI 요청 schema·한도·키 비노출·거절/불완전/429 응답 처리, 학습만 보는 반복·실패 피드백·원본 응답 대조를 mock으로 검증. AI 가설 생성 시점 이전의 forward 기간은 승격 차단.

## 아직 완료하지 않은 항목

- KRX/OpenDART 실제 인증 호출: 실행 환경에 KRX_API_KEY, OPENDART_API_KEY가 없음. 인증키 및 KRX 서비스 활용 승인이 필요.
- 실제 국내 종목의 역사적 universe/산업 분류/공식 거래일/공개시각/상장폐지·기업행위 품질 검토와 원본 수집.
- 실제 기간·시장·증권사별 비용, 위험·통계 gate 기본값의 Owner 검토.
- 실제 주문 대기열·호가 잔량·시장별 호가 단위·기업행위 조정 모델. 이전 거래량 기반 participation/부분체결 근사는 구현했으나 검증된 실전 체결 시뮬레이터는 아님.
- 외부 LLM의 실제 API 인증·모델/비용 설정과 실제 가설 생성 호출. API client와 학습 피드백 worker, cohort 연결은 구현했으나 OPENAI_API_KEY가 없고 예시 설정은 비활성화.
- 검증된 실시간 관측 adapter 및 실제 forward paper 세션. 수동 입력 파일은 실전 시세로 인증하지 않음.
- 장기간 양의 기대값, 반복 가능 수익성, 일평균 1% 접근 가능성 검증. 코드/합성 테스트 완료는 이 증거를 대체하지 않음.
- DB 기존 schema 업그레이드용 migration과 분산 실행. 로컬 파일 저장/세션 commit은 원자적으로 게시하지만 DB와 파일의 분산 트랜잭션이나 다중 호스트 실행을 지원한다고 주장하지 않음.

## 이어서 진행할 작업

Owner가 인증키 발급·서비스 승인을 완료했으며 로컬 환경변수로 설정하겠다고 답변했습니다. 실행 환경에서 키를 확인한 뒤 공식 API의 실제 응답을 보존하고 품질 검토를 시작합니다. 프로세스 환경변수 또는 Windows 사용자 환경변수에서 읽고 값은 출력하지 않습니다. 키를 채팅이나 Git에 넣지 않습니다. KRX는 과거 일봉 공급원으로 선택했고, 실시간 관측 공급원은 아직 선택하지 않았습니다. 실제 데이터 검증과 paper 증거가 없는 상태에서는 목표를 완료로 표시하지 않습니다.

Owner의 계속 시도 요청 이후, 앞서 논의한 단일 cohort 검증 구조와 OpenAI 연구 worker를 구현해 설계 대기만으로 작업을 멈추지 않도록 했습니다. 실제 인증키·모델과 호출 예산·시장 정책·시세 공급원 및 실제 경과 기간이 필요한 항목은 미완료로 유지합니다. 검증 기준을 낮추거나 가공 데이터를 실전 성과로 표시하지 않습니다.
