# 우선 목표

한국 주식시장에서 반복 가능하고 통계적으로 검증 가능한 단기 투자 전략을 발견하고 실행하는 시스템을 구축한다. 수익률 최대화는 비용·슬리피지, 시점별 정보, 학습/검증 분리, walk-forward, MDD/일손실 한도, 전략 분산, paper 우선 평가, regime 중단, 검증 전 실주문 금지의 제약 안에서만 수행한다.

일평균 1%는 연구 측정 목표다. 위험 확대나 검증 완화의 근거가 아니다. 현재 실행 범위는 가상 거래뿐이며 실제 주문 API와 자격증명은 추가하지 않는다.

최신 계속 구현 요청은 첨부 문서의 M1 이후 중단 조건을 대체한다. 실제 수익 검증은 실제 시장 데이터와 경과 시간이 필요하므로 코드 완료와 구분한다.

# 실행 계획

1. Core: 시점별 OHLCV/Universe, 전략 버전, 비용·위험 설정, 재현 정보.
2. Persistence: PostgreSQL/EF Core, 원본 데이터와 불변 실험 결과. CLI는 파일 저장으로도 엔진 검증 가능.
3. MarketData: 명시적 timestamp와 거래 가능 플래그를 가진 CSV. KRX 공식 API는 인증키/이용 조건 확인 후 연결. 현재 구성종목을 과거 전체에 적용하지 않는다.
4. Strategies: 종가 모멘텀과 평균회귀, 판단일 이후 시가 체결. 신호와 주문 책임 분리.
5. Backtest: long-only, 무레버리지, 정수 주식, 수수료·매도세·슬리피지, 포지션/전략/섹터 한도, 거래정지 시 청산 지연.
6. Research: train/validation/test 분리, 시간 순서 walk-forward, 마지막 holdout 봉인, 후보 수를 반영한 통계 평가. 부적합 결과 보존.
7. Paper: 실시간 관측만 허용하는 증분 이벤트 기록, 과거 재생은 paper 성과로 인정하지 않는다. 위험/상태 gate 적용.
8. Tests: 미래값 변형 불변성, 비용/장부, gap/정지, 손실 한도, 분할 누수, 재현성, 증거 gate.

가상 연구 기본값은 승인된 투자 정책이 아니다. 거래비용은 날짜/시장별 실제 요율을 사용자가 제공해야 한다. 비교용 기본값은 현실 수수료/세금에 관한 주장이 아니다.

작업은 foundation / data / execution / validation / paper-evaluation의 5개 검토 단위로 나눈다. Owner 요청에 따라 현재 기반 구현을 공개 GitHub 저장소 `hyeyoung7264/krx-strategy-research`에 게시한다. 공개 게시가 전체 목표 완료나 실전 유효성 검증을 의미하지 않는다. PR 생성과 merge는 이번 게시 범위에 포함하지 않는다.

Owner의 반복 시도 요청에 따라 단일 cohort에서 전략군별 후보와 결합 포트폴리오를 검증하는 경로를 구현한다. 개별 후보와 가능한 조합 전체를 사전 등록하고 동일 holdout의 여러 검정을 독립 실험으로 세지 않는다. 데이터 revision으로 기존 holdout 예약을 우회하지 않는다. AI 후보 생성은 익명화한 학습 구간과 실패 피드백에 한정하며 가설 생성 전의 forward 구간으로 승격하지 않는다. 실제 시장 검증과 실시간 시세·장기 paper 자료는 코드 테스트로 대체하지 않는다.

2026-09-29 밤 Owner가 부재 중에도 목표를 향해 독립적으로 진행하도록 권한을 위임했다. 데이터 조사·수집, 필요한 구현 선택, 검증·오류 수정과 승인된 공개 저장소 반영을 계속 수행한다. 기존 목표의 검증·위험 제약과 현재 가상 거래 범위는 유지한다. 비용·통계 정책도 실제 근거와 적용 조건을 확인해 검토하며, 위임 자체를 자료 검증 완료나 `PolicyReviewed=true`의 근거로 삼지 않는다. 자격증명 또는 외부 관측 기간처럼 실제로 없는 증거는 만들어 대체하지 않는다.
