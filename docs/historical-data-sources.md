# 역사 데이터 확보 경로와 남은 증거

2026-09-29 읽기 전용 공식 자료 조사와 실제 응답 검토 결과다. 장기 가격 원본을 수집할 수 있는 상태와 편향 없는 전략 검증용 자료를 완성한 상태를 구분한다.

## 세션 달력

[KRX 공식 휴장일 화면](https://global.krx.co.kr/contents/GLB/05/0501/0501110000/GLB0501110000.jsp)은 현재 2016~2026년 선택을 제공한다. `krx-calendar`는 공개 화면의 연도 선택을 확인하고 같은 공식 호스트의 공개 폼 토큰·조회 절차로 연간 원본을 보존한다. 인증키가 필요 없는 공개 화면이며 지원 계약이 있는 Open API는 아니다. 화면 변경·리디렉션·HTML 오류·빈/잘못된 JSON은 중단한다. 공식 서버는 식별 가능한 User-Agent를 요구했고, 정상 JSON의 MIME이 text/html인 응답도 엄격한 본문 검증 후 처리한다.

2026년 목록에는 17개 휴장 날짜가 있었고, 9월 1~28일의 주말과 휴장 날짜를 제외한 후보 18일은 실제 수집한 날짜들과 일치했다. 이 자료가 과거 일봉의 공개시각·특별 개장 시각·결제일 달력을 인증하지는 않는다. 가격 API의 빈 응답을 휴장 근거로 대체하지 않는다.

## 상장·폐지·거래정지

| 공식 출처 | 용도 | 한계 |
|---|---|---|
| [과거 매매거래정지·재개 내역](https://data.krx.co.kr/contents/MDC/STAT/issue/MDCSTAT213.jsp) | 종목별 정지·재개 구간 대조 | [현재 정지 목록](https://data.krx.co.kr/contents/MDC/STAT/issue/MDCSTAT212.jsp)으로 과거를 대체하지 않는다. |
| [상장폐지 현황](https://data.krx.co.kr/contents/MDC/STAT/issue/MDCSTAT238.jsp) | 상장/폐지일·사유·증권 종류 대조 | 업종은 폐지 직전 최종 거래일 기준이라 과거 산업 이력이 아니다. |
| [상장폐지 종목 시세](https://data.krx.co.kr/contents/MDC/STAT/issue/MDCSTAT239.jsp) | 폐지된 종목의 과거 가격 보존 | 폐지 후 현금 회수·잔존 권리를 증명하지 않는다. |

정보데이터시스템의 익명 조회는 `LOGOUT` 응답이었다. 정상 로그인 후 공식 다운로드가 필요하고, 이를 빈 자료로 처리하거나 로그인 제한을 우회하지 않는다. 표준종목코드(ISIN)와 날짜로 일별 원본을 대조해야 한다. 현재 생존 종목만 선택해 과거 수익을 계산하지 않는다.

별도 [공개 KIND 상장폐지현황](https://kind.krx.co.kr/investwarn/delcompany.do?method=searchDelCompanyMain)은 인증 없이 정상 GET 조회할 수 있었다. 2026년 9월 범위의 HTML 응답 10행·1페이지 중 로컬 감사의 소멸 8건을 회사 링크 식별자·시장·이름·날짜로 대조했고 공식 폐지일/사유가 일치했다. 표의 회사 링크는 5자리 식별자이며 ISIN·전체 종목코드·최초 공시시각·회수액을 제공하지 않는다. 모든 식별자에 임의로 0을 붙여 종목코드로 변환하지 않는다. 이 공개 경로의 현재 현황을 당시 공개된 매도 신호나 정산 가격으로 소급하지 않는다. 지원되는 API 계약은 아니므로 자동 수집 시 HTML 구조·전체 건수·페이지 경계·중복을 검증하고 원본을 보존해야 한다.

## 기업행위와 보유 권리

[KIND의 실제 분할 공시 예](https://kind.krx.co.kr/external/2024/11/15/000107/20241115000180/68155.htm)는 비율·효력일·표준코드·매매재개일을 제공한다. 원공시와 정정을 별도로 보존하고 각 시점에 공개된 내용을 사용해야 한다. 총 상장주식 수 증가가 기존 주주의 보유수량 증가를 뜻하지 않으므로, 일봉의 주식 수 변화만으로 포지션을 곱하지 않는다. [수정주가 설명](https://data.krx.co.kr/contents/MDC/STAT/issue/MDCSTAT201.jsp)도 비교용 조정가격과 실제 과거 현금 체결가격·권리 장부를 동일시하는 근거가 아니다.

[금융위원회·예탁결제원 주식발행정보 API](https://www.data.go.kr/en/data/15043423/openapi.do)는 별도 공공데이터포털 서비스키와 승인이 필요하다. 일일 갱신은 다음 영업일 13시 이후로 안내하므로, 기준일이 전일이라는 이유로 다음날 시가에 이미 알았던 자료로 사용할 수 없다. 과거 원본 버전·정정 이력과 모든 권리 종류의 완전성은 미확인이다. [KRX 유료 EOD 자료](https://openapi.krx.co.kr/contents/OPP/DATA/OPPDATA002.jsp)도 기업 사건 자료의 후보이지만 필드·기간·이용 조건·가격을 확인해야 한다. 구매나 신규 신청은 하지 않았다.

우선 후보 달력과 모든 당시 종목의 일별 가격/기본정보를 보존하고, 누락·종목 출현/소멸·주식 수 변화·큰 미조정 가격 변화를 자동 감사한다. 이어 공식 사건 자료와 대조하고 보유 권리·정산 회계를 구현한다. 산업 분류·원본 공개시각·정확한 체결비용 증거도 갖춰야 한다. 해결되지 않은 상장폐지/기업행위 포지션은 0원 회수나 과거 제외로 처리하지 않고 계산을 중단한다.
