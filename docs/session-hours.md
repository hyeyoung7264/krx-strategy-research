# 날짜별 정규장 시간

모든 거래일을 09:00~15:30으로 가정하면 특별 개장일의 체결과 정보 공개 순서가 달라진다. 예를 들어 2025-01-02 정규장은 10:00~15:30이었다. 양 시장의 [KOSPI 공지](https://kind.krx.co.kr/external/2024/12/17/000106/20241217000237/99303.htm)와 [KOSDAQ 공지](https://kind.krx.co.kr/external/2024/12/17/000102/20241216000236/70780.htm)를 확인하고 원문 바이트를 로컬에 보존했다. 이 공지를 오늘 관측했다는 사실만으로 역사적 최초 공개시각을 채우지는 않는다.

## 입력과 적용 범위

`Dataset`과 `KrxManifest`의 `SessionHours`에 날짜별 검토 입력을 넣는다. `Sessions`는 거래일 목록이고, `SessionHours`는 그 날짜의 정규장 시간과 근거다.

| 필드 | 의미 |
|---|---|
| `Date` | 한국 시간 기준 거래일 |
| `OpenAt` | 해당 정규장 개장 시각 |
| `CloseAt` | 해당 정규장 마감 시각 |
| `AvailableAt` | 이 일정이 판단에 사용 가능해진 검토된 시각 |
| `Evidence` | 시간과 공개시각을 검토한 근거 |

개장·마감은 한국 시간으로 같은 `Date`에 속해야 하고 개장이 마감보다 빨라야 한다. 일정은 날짜순·중복 없음·공개시각이 개장 이하·비어 있지 않은 근거를 요구한다. UTC 등 다른 offset으로 표현한 같은 시각은 한국 날짜로 판정한다.

인증 dataset은 모든 실제 거래일의 명시적 시간표를 요구한다. 미검토·합성 자료의 `SessionHours=null`에는 기존 기본 시각을 허용하지만, 시간표를 명시한 뒤 빠진 날짜를 기본 시각으로 대체하지 않는다. 필드를 생략한 구형 JSON은 합성·미검토 진단에 사용할 수 있으며, 구형 인증 자료를 자동으로 재인증하지 않는다. 과거 연구 아카이브는 그때의 실행 소스로 재현한다.

현재 범위는 같은 정규장 일정을 쓰는 KRX 현물 연구다. 시간외 거래·NXT 통합 시세·거래소별 혼합 시간표의 체결 모형을 제공하지 않는다. 원문 수집기의 기존 시간 하한 검사도 실제 세션이나 과거 공개시각 인증이 아니다.

## 계산과 검증 구간

백테스트의 시가 판단·체결·종가 평가, 일봉 공개 하한, 상장 사건 공개시각, 분할·병합의 효력 및 입고 검사는 실제 시간표를 사용한다. 10시 개장일에는 09:30에 공개된 전일 자료를 시가 직전 판단에 사용할 수 있다. 16:30 마감일의 일봉을 15:30에 이미 공개됐다고 입력하면 거부한다. 시간표 자체도 판단 전에 알려져 있어야 한다.

학습과 비용 진단에는 잘라낸 구간의 시간표와 필요한 과거 효력일 근거만 남긴다. 다음 검증/holdout 개장 시각은 분리 경계를 계산하는 데 쓰고 그 미래 시간표 행·근거를 학습 hash나 프롬프트에 넣지 않는다. 이미 알려진 미래 가격 단위 전환일은 사건 조건으로 보존할 수 있지만 그날의 시간표를 미리 가져오지 않는다.

인증 dataset에서 분할·병합 효력일은 명시된 실제 거래일이어야 한다. 휴장일 효력 발생의 정확한 경제 시각은 현재 지원하지 않으므로 실행을 거부한다. 다음 거래일로 옮기거나 가상의 휴장일 세션을 만들지 않는다. 미검토 기존 진단의 기본 시각 계산은 실제 권리 시각을 인증하지 않는다.

## Paper 관측

`PaperState`는 시작 연구의 시간표를 보존하고 `Observation.SessionHours`로 새 날짜 일정을 추가할 수 있다. 명시적 시간표를 사용한 세션은 해당 날짜의 첫 open 관측에 누락된 일정을 제공해야 하며, 기존 날짜 수정은 거부한다. 새 일정의 공개시각은 관측시각과 개장시각 이하여야 한다. 이미 처리한 시간 이전의 일정을 끼워 넣어 잔고를 다시 계산하지 않는다.

개장 관측은 실제 개장부터 5분 이내이며, quote 관측은 실제 정규장 안에 있어야 한다. open/quote의 가격시각도 개장 이상이며 관측 전 10초 이내여야 한다. close 수신에는 마감 후 10분의 여유를 두고 가격시각은 실제 마감 전 10초부터 마감까지로 제한한다. 마감 뒤 수신한 관측으로 새 체결을 만들지 않는다. 가치 평가와 위험 중단은 유지하고 청산은 이후 거래 가능한 관측에서 처리한다. 마감 정시 관측의 기존 단순 체결 근사는 남아 있으며 종가 단일가 주문·잔량을 검증한 체결 모형은 아니다.

시간표와 추가 관측은 상태 및 장부 hash에 포함되고 재생 시 같은 규칙으로 검증한다. 파일로 넣은 일정·시세는 공급원 인증이 아니며 `VerifiedFeed=false`는 유지한다. 이 기능의 회귀 테스트는 회계·시간 경계의 계산 검증이고 실제 forward paper 성과가 아니다.
